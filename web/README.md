# Route 9 EJ Explorer

Interactive data explorer and open-source research portal for the independent study
**"Spatial Equity, Traffic Exposure, and Environmental Justice along the Route 9 Corridor (Worcester & Shrewsbury, MA)."**

A static React + Tailwind site (no backend, no tracking) that reads the analysis outputs already in this repository.

| Section | What it does |
| --- | --- |
| Hero & executive summary | Headline findings, recomputed from the CSV at load time |
| Corridor explorer | Choropleth of all 166 block groups (real Census TIGER polygons + Route 9), 4 map layers, distance-band isolation, linked scatter plot, live corridor-radius slider, sortable hotspot table, Figure 1 |
| Air quality hub | PM2.5 vs WHO / EPA benchmarks, exceedances, seasonality, monitors, Figure 2 |
| Evidence | Forest plot of Spearman correlations with cluster-bootstrap CIs, corridor tests, robustness tables |
| Methodology & code | Six-step pipeline, key parameters, reproduce commands, data sources, limitations |
| Resources | Paper PDF, dataset download, repository link, abstract, citation, data dictionary |

## Quick start

```bash
cd web
npm install
npm run dev        # http://localhost:5173
npm run build      # audit -> typecheck -> static site in web/dist
npm run preview
```

Requires Node 20+.

## How the existing workspace is used (nothing is overwritten)

`npm run data` (run automatically by `dev` and `build`) executes `scripts/build-data.mjs`, which only **reads** the repo root:

| Source (untouched) | Used for |
| --- | --- |
| `../outputs/master_route9_table.csv` | Copied verbatim to `public/data/` for download; parsed into `src/data/generated/blockgroups.json` |
| `../charts/figure1_income_traffic_ej.png`, `figure2_pm25_distribution.png` | Copied verbatim to `public/figures/` |
| `../route9_deep_analysis.py` | Copied verbatim to `public/code/` for download |
| `../outputs/summary_statistics.txt` | Copied to `public/data/`; its numbers are used for the **audit** below |
| `../cache/tl_2024_25_*.zip` (Census TIGER) | Block-group polygons, Route 9 centreline and town outlines, simplified to ~3 m for display, in `src/data/generated/geometry.json` |

**Audit step.** Before building, the script re-derives the headline numbers from the CSV (block-group counts, 78/81 corridor EJ, 33 hotspots,
Spearman rho, the $10,651/km OLS slope, band medians, residents within 300 m / 500 m / 1 km, AADT) and compares them to the values
printed in `summary_statistics.txt`. If the CSV and the report ever disagree, the build fails.

`src/data/generated/` is committed so a fresh clone builds without the 15 MB TIGER cache. If the cache is present it is used to regenerate the geometry.

Values that cannot be recomputed from the CSV (bootstrap CIs, Mann-Whitney / Cliff's delta, Moran's I, PM2.5 statistics) are transcribed from
`summary_statistics.txt` and Figure 2 into `src/components/Evidence.tsx` and `src/data/airQuality.ts`, each with a source comment.
Update them when you re-run the analysis.

## Filling in the remaining placeholders

Most assets are live. Everything still open is controlled from **`src/config.ts`**. Leave a link as `""` and its slot renders a clean "Coming soon" state; set it and the slot becomes a live link.

```ts
export const LINKS = {
  paperPdf: asset("paper/route9-ej-study.pdf"), // live
  githubRepo: "",   // e.g. "https://github.com/<user>/route9-ej-study"
  datasetCsv: asset("data/master_route9_table.csv"), // live
  ...
};
export const SITE = {
  author: "Vikram Angiras",
  affiliation: "Independent research",
  year: 2026,
  contactEmail: "", // optional mailto in the footer
};
```

- **Paper PDF:** `web/public/paper/route9-ej-study.pdf` (committed; not regenerated by `npm run data`).
- **Paper abstract:** `src/content/paper-abstract.md` (rendered as Markdown in Resources).
- **Citation / BibTeX:** completes the repository URL once `LINKS.githubRepo` is set.
- **Data dictionary:** `src/data/dictionary.ts` (one entry per CSV column).
- **License:** add a root `LICENSE` before publishing (e.g. MIT for code, CC BY 4.0 for data/figures).

## Deploying (GitHub Pages)

This is a **Vite + React** app in `web/`, not a plain HTML site. GitHub Pages cannot serve the repo root as-is (there is no root `index.html`); the site must be **built** first.

1. In the repo: **Settings → Pages → Build and deployment → Source → GitHub Actions** (not “Deploy from a branch”).
2. Push to `main`. The workflow `.github/workflows/deploy.yml` runs `npm ci` + `npm run build` in `web/` and publishes `web/dist`.
3. Site URL: `https://vikramangiras2027.github.io/Route_9_EJ_Study/`

Local / non-Pages builds still use `base: "./"`. CI sets `GITHUB_PAGES=1` so Vite uses `base: "/Route_9_EJ_Study/"`.

## Interpretation guardrails (also stated on the site)

- Traffic exposure is **modelled** from one MassDOT station using AADT x exp(-d/300 m), not measured.
- PM2.5 comes from two monitors ~23 km apart and is **regional context**, not a corridor-specific measurement.
- All results are ecological, neighborhood-level associations, not individual exposure, health outcomes or causation.
